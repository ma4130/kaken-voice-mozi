# VOICE ART

https://ma4130.github.io/kaken-voice-mozi/

声を立体文字に変えて漂わせる、常時表示の音声アート。時間制限・スコア・ターゲットはありません。マイクボタンで音声入力を開始し、声量に応じて文字が大きくなります。日本語音声認識対応時は認識した言葉を表示。認識が確定した言葉だけを表示します。無音・物音・タップから決められた言葉を出す処理はありません。

ローカル起動: `python -m http.server 8190`

音声はアプリに保存しません。音声認識はブラウザー提供サービスへ送信される場合があります。
